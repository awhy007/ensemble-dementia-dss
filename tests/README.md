# Prototype tests

`test_prediction.py` contains the automated tests for input validation and prediction behaviour. The suite covers valid cases, accepted boundary values, missing and invalid inputs, whole-number requirements, deterministic predictions, numeric text and model-bundle integrity.

Run the tests from the repository root with:

```powershell
python -m pytest -q
```

The tests use fictional demonstration cases only. No participant or patient information is stored in this directory.
